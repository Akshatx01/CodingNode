# How to Run Programs

## C++ Programs

### Compile

```bash
g++ <fileName.cpp> -o <outputName>
```

Example:

```bash
g++ index.cpp -o index
```

### Run

Linux/macOS:

```bash
./index
```

Windows:

```bash
.\index.exe
```

---

## C Programs

### Compile

```bash
gcc <fileName.c> -o <outputName>
```

Example:

```bash
gcc index.c -o index
```

### Run

Linux/macOS:

```bash
./index
```

Windows:

```bash
.\index.exe
```

---

## Python Programs

### Run

```bash
python <fileName.py>
```

Example:

```bash
python index.py
```

---

## JavaScript (Node.js)

### Run

```bash

```

Example:

```bash

```

# Basic Terminal Commands

## Change Directory

Enter a folder:

```bash
cd <folderName>
```

Go back one level:

```bash
cd ..
```

---

## List Files and Folders

Linux/macOS:

```bash
ls
```

Windows:

```bash
dir
```

Displays all files and folders in the current directory.

---

## Create a New Folder

```bash
mkdir <folderName>
```

Example:

```bash
mkdir Projects
```

Creates a new directory from the terminal.
